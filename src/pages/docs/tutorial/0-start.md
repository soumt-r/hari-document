> **이 장에서 배울 것**
> - 이 문서 안에서 코드를 바로 실행하는 방법
> - 첫 번째 프로그램 만들기
> - 하리 문장이 어떻게 생겼는지 (기호 네 가지, 조사, 들여쓰기)
> - 오류가 났을 때 메시지를 읽는 법

프로그래밍을 한 번도 해 본 적이 없어도 괜찮아요. 이 장은 아무것도 모른다고 생각하고 시작해요.

---

### 프로그램이란?

**프로그램**은 컴퓨터에게 할 일을 차례대로 적어 둔 글이에요. 요리법이 "물을 끓이자 → 면을 넣자 → 3분 기다리자"처럼 순서대로 적혀 있듯이, 프로그램도 **위에서 아래로 한 줄씩** 실행돼요.

하리로 쓴 프로그램은 이렇게 생겼어요.

```hari
"안녕하세요!"를 출력하자
```

`출력하자`는 "화면에 보여 주자"라는 뜻이에요. 그러니 이 프로그램은 화면에 `안녕하세요!`를 보여 줘요.

---

### 코드를 직접 실행해 보기

이 문서의 코드 상자는 모두 **직접 실행할 수 있어요.** 설치할 것은 없어요.

1. 위 코드 상자의 오른쪽 위에 있는 **실행** 버튼을 눌러 보세요.
2. 상자 아래에 **결과** 칸이 열리고 `안녕하세요!`가 나타나요.
3. 상자 안의 글자를 고칠 수도 있어요. `안녕하세요!`를 `반가워요!`로 바꾸고 다시 실행해 보세요.

코드를 망가뜨려도 걱정하지 마세요. 페이지를 새로 고치면 원래대로 돌아와요. 빈 화면에서 마음대로 써 보고 싶다면 왼쪽 목차 아래의 **직접 실행해보기** 버튼을 누르거나, 맨 위 메뉴의 **놀이터**로 가면 돼요.

---

### 여러 줄은 순서대로 실행돼요

```hari
"하나"를 출력하자
"둘"을 출력하자
"셋"을 출력하자
```

실행하면 `하나`, `둘`, `셋`이 한 줄씩 차례로 나와요. 줄의 순서를 바꾸면 나오는 순서도 바뀌어요. 프로그램은 언제나 **위에서 아래로** 흘러간다는 것을 기억해 두세요.

---

### 하리 문장 읽는 법

하리 문장은 우리말처럼 **"무엇을 + 어떻게 + 하자"** 로 되어 있어요.

| 문장 | 읽는 법 |
|---|---|
| `"안녕"을 출력하자` | "안녕"**을** 화면에 **출력하자** |
| `'점수'를 10으로 정하자` | '점수'라는 이름표**를** 10**으로** **정하자** |
| `'점수'에 5를 더하자` | '점수'**에** 5**를** **더하자** |

문장의 끝에는 항상 `~하자`, `~만들자` 같은 **동사**가 와요. 이 동사가 컴퓨터가 할 일이에요.

#### 기호 네 가지

하리는 따옴표와 괄호 모양만 봐도 그것이 무엇인지 알 수 있어요. 이 네 가지만 기억하면 하리 코드를 읽을 수 있어요.

| 기호 | 뜻 | 예 |
|---|---|---|
| `"글자"` (큰따옴표) | 화면에 보여 줄 **글자 그대로** | `"안녕하세요"` |
| `'이름'` (작은따옴표) | 값을 담아 두는 **이름표** (변수) | `'점수'`, `'이름'` |
| `[종류]` (대괄호) | 값의 **종류** (타입) | `[숫자]`, `[문자열]` |
| `<기능>` (꺾쇠) | 미리 만들어 둔 **기능** (함수) | `<문자로>()` |

특히 큰따옴표와 작은따옴표를 헷갈리기 쉬워요. `"점수"`는 **점수라는 글자**이고, `'점수'`는 **점수라는 이름표에 담긴 값**이에요.

```hari
'점수'를 100으로 정하자
"점수"를 출력하자
'점수'를 출력하자
```

첫 번째 출력은 `점수`라는 글자를, 두 번째 출력은 이름표에 담긴 `100`을 보여 줘요.

#### 조사는 편하게 써도 돼요

`을`/`를`, `로`/`으로`는 앞 글자의 받침에 맞춰 쓰면 읽기 좋아요. 하지만 틀리게 써도 하리는 똑같이 알아들어요.

```hari
"사과"를 출력하자
"사과"을 출력하자
```

두 줄 모두 `사과`를 출력해요. 처음에는 조사 걱정은 하지 말고 편하게 쓰세요.

---

### 묶음: 콜론(`:`)과 들여쓰기

어떤 문장은 "이 아래의 일들을 묶어서 하자"라는 뜻을 가져요. 이런 문장은 끝에 **콜론(`:`)** 을 붙이고, 묶이는 줄들은 **안쪽으로 들여 써요.**

```hari
만약 참 라면:
    "이 줄은 묶음 안에 있어요."를 출력하자
    "이 줄도 묶음 안에 있어요."를 출력하자
"이 줄은 묶음 밖에 있어요."를 출력하자
```

- 들여쓰기는 **스페이스 4칸**을 권해요. 탭을 써도 되지만, 한 묶음 안에서는 모두 같은 칸만큼 들여 써야 해요.
- 들여쓰기가 끝나는 곳에서 묶음도 끝나요. 위 예에서 마지막 줄은 묶음과 상관없이 항상 실행돼요.

`만약`(조건)과 `반복하자`(반복)를 배울 때 이 묶음을 자주 쓰게 돼요. 지금은 "콜론 다음 줄은 들여 쓴다"만 기억하세요.

---

### 메모 남기기: `(참고)`

`(참고)`를 쓰면 그 뒤부터 줄 끝까지는 **컴퓨터가 읽지 않는 메모**가 돼요. 코드가 무슨 일을 하는지 사람에게 알려 줄 때 써요.

```hari
(참고) 아래 줄은 인사를 출력해요.
"안녕하세요!"를 출력하자
"반가워요!"를 출력하자 (참고) 줄 끝에도 메모를 달 수 있어요.
```

---

### 오류가 났을 때

코드를 쓰다 보면 오류는 반드시 만나요. 오류는 "여기가 이상해요"라고 알려 주는 **도움말**이니 겁먹지 않아도 돼요. 아래 코드는 `출력하자`를 `출력하쟈`로 잘못 썼어요. 실행해 보세요.

```hari fail
"안녕"을 출력하쟈
```

결과 칸에 **"1번째 줄에서 문장이 끝나지 않았어요."** 같은 메시지가 나와요. 오류 메시지는 대부분 두 가지를 알려 줘요.

1. **어디서**: 몇 번째 줄(때로는 몇 번째 글자)인지
2. **무엇이**: 무엇이 이상한지

그 줄로 가서 오타가 없는지, 따옴표를 열고 닫았는지 살펴보세요. 초보자가 자주 만나는 오류는 다음과 같아요.

| 이런 메시지가 나오면 | 이렇게 확인하세요 |
|---|---|
| 문장이 끝나지 않았어요 | 동사(`출력하자` 등)에 오타가 없는지 |
| `'"'`를 이해할 수 없어요 | 따옴표를 열고 닫았는지 (`"안녕"` ← 양쪽 다) |
| `'점수'` 변수를 찾을 수 없어요 | 그 이름표를 먼저 `정하자`로 만들었는지, 이름에 오타가 없는지 |

더 많은 오류와 해결법은 [부록. 자주 만나는 오류](/docs/tutorial/common-errors)에 모아 두었어요.

---

### 내 컴퓨터에서 실행하려면 (나중에 해도 돼요)

이 문서만으로 끝까지 배울 수 있어요. 파일을 읽고 쓰거나 실행 파일을 만드는 것처럼 브라우저에서 할 수 없는 일이 필요해지면, 그때 [Hana 런타임](/docs/hana/intro)을 설치해서 `hana run 파일이름.hr`로 실행하면 돼요.

---

### 정리

| 배운 것 | 예 |
|---|---|
| 화면에 보여 주기 | `"안녕"을 출력하자` |
| 프로그램은 위에서 아래로 | 줄 순서 = 실행 순서 |
| 글자와 이름표 | `"점수"`는 글자, `'점수'`는 이름표에 담긴 값 |
| 묶음 | 콜론(`:`) 다음 줄을 들여 쓰기 |
| 메모 | `(참고) …` |
| 오류 읽기 | 몇 번째 줄 + 무엇이 이상한지 |

### 연습 문제

**1.** 아래 코드를 고쳐서 여러분의 이름으로 인사하는 세 줄을 출력해 보세요.

```hari
"안녕하세요!"를 출력하자
"제 이름은 하리예요."를 출력하자
"만나서 반가워요."를 출력하자
```

**2.** 아래 코드에는 오류가 하나 있어요. 실행해서 메시지를 읽고 고쳐 보세요.

```hari fail
"오늘의 날씨를 출력하자
```

<details>
<summary>정답 보기</summary>

큰따옴표를 닫지 않아서 하리가 글자가 어디서 끝나는지 알 수 없어요. 글자 뒤에 `"`를 붙이면 돼요.

```hari
"오늘의 날씨"를 출력하자
```

</details>

**3.** 아래 코드를 실행하기 전에, 무엇이 어떤 순서로 나올지 먼저 예상해 보세요. 그다음 실행해서 맞혀 보세요.

```hari
"처음"을 출력하자
(참고) "중간"을 출력하자
만약 참 라면:
    "묶음 안"을 출력하자
"끝"을 출력하자
```

<details>
<summary>정답 보기</summary>

`처음`, `묶음 안`, `끝`이 차례로 나와요. 두 번째 줄은 `(참고)`로 시작해서 메모가 되었기 때문에 실행되지 않아요.

</details>

다음 장에서는 값을 이름표에 담아 두는 **변수**를 배워요.
